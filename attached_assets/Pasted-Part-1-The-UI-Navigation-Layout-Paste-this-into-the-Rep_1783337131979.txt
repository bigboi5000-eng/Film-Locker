Part 1: The UI & Navigation Layout

Paste this into the Replit Agent first to build the visual foundation:

"Build a native mobile application called 'Film Locker' using React Native and Expo.

DESIGN SYSTEM:

Theme: Clean White-based light mode.

Accents: Use #0066FF (Blue) and #FF8C00 (Orange) for all icons, buttons, and active states.

NAVIGATION (3-Tab Bottom Bar):

Home Screen: Display two horizontal scrolling sections: 'New Releases' and 'Trending Online'. Use TMDB API to populate these.

My Watchlist:

Top section: A search bar to manually find/add films and a 'Paste Link' input for social media captions.

Middle: A filter bar allowing users to filter the list by Director, Actor, Language, Genre, and Streaming Service.

Bottom: A grid of movie posters representing the user's saved items.

Watched: A mirrored grid of posters for films the user has finished. Include the same filter bar as the Watchlist.

FILM DETAIL VIEW:

When a movie is tapped, open a modal showing: Large Poster, Title, Date, Director, Genre Tags, Lead Actors, and Language. Include a 'Where to Stream' section. Beneath this, a section of the film/tv synopsis.

INTERACTION LOGIC:

On the Film Detail page, include a 5-star rating component and a 'Mark as Watched' button.

If a film is marked as 'Watched', it must instantly move from the Watchlist tab to the Watched tab in the PostgreSQL database."

Part 2: The Logic & AI Integration

Once the Agent finishes the UI, paste this to wire up the "multimodal" brain we discussed:

"Now, let's integrate the intelligence engine. We are using Google Gemini (Gemini-3.5-Flash) and TMDB.

LINK PROCESSING FLOW:

When a user pastes a link in the Watchlist tab, use a scraper to get the caption.

If no caption is found, use yt-dlp on the backend to download the audio.

Pass either the text OR the audio file directly to Gemini using the multimodal @google/genai library.

Gemini must extract: movie_title and release_year.

METADATA ENRICHMENT:

Take the clean title from Gemini and query TMDB to get: Poster URL, Director, full Cast list, Genres, and 'Watch Providers' for streaming info.

Save all these details into the PostgreSQL database under the user's account so the filters (Director, Actor, Language, etc.) work accurately."

Pro-Tips for testing this in Replit:

The "Streaming" Data: TMDB provides streaming info via a service called "JustWatch." Tell the Agent to look for the watch/providers endpoint in the TMDB API to get those logos.

Filtering: Because you want to filter by Actor and Director, the database needs to save those as arrays (lists). The Replit Agent is usually good at this, but if the filters don't work, just tell it: "Make sure Director and Actors are stored as searchable tags in the database."

The Icons: Since you specifically asked for Blue and Orange, the Agent will likely use a library called Lucide or FontAwesome. It will look incredibly sharp against the white background.
